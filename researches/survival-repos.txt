Repositorios de GitHub útiles para supervivencia y para ejecutar IA local en un PC
Repositorios con manuales de supervivencia completos (wikis descargables)
Repositorio (enlace a GitHub)	Contenido resumido
ligi/SurvivalManual	Manual de supervivencia libre basado en el manual del ejército de EEUU. La página "About" indica que se trata de una guía basada en el manual público FM 3‑05.70 (FM 21‑76) y está pensado para funcionar sin conexión. La wiki del repositorio contiene capítulos sobre psicología, planificación, kits, medicina básica, agua, fuego, alimentos y más. Puedes clonar el repositorio o ir a la pestaña Wiki para descargar cada capítulo, y el proyecto ofrece una aplicación Android en F‑Droid y Amazon para acceder al manual sin conexión.
inferno986return/SurvivalManual‑ebook	Proyecto de la comunidad que convierte el contenido del wiki de SurvivalManual en un ePub/PDF. El README señala que usa git clone para copiar todo el contenido de la wiki y que el manual (ePub) pesa menos de 4,5 MB. Su objetivo final es ofrecer una versión imprimible para que el manual funcione incluso sin energía. En el directorio releases puedes descargar la versión más reciente del libro electrónico.
CreativeLyons/NukeSurvivalToolkit_Wiki	Aunque orientado a la herramienta de posproducción Nuke, este repositorio ofrece un ejemplo de wiki que puede leerse sin conexión. La página principal explica que la wiki puede consultarse en línea y que también puedes descargar un archivo ZIP con la wiki completa para uso sin conexión. También ofrece scripts para exportar la documentación a PDF.
alx‑xlx/awesome‑survival	Una lista awesome de recursos de supervivencia. Incluye enlaces a manuales, blogs, foros y aplicaciones; por ejemplo, recomienda la aplicación Survival Manual (F‑DROID) en la sección de aplicaciones. No es un manual per se, pero sirve como punto de partida para localizar más documentación y kits.
danielfeitopin/manual‑supervivencia‑fic	Manual de supervivencia redactado por dos estudiantes de la Facultad de Informática de Coruña. El repositorio contiene el archivo LaTeX y un PDF con el “Manual de Supervivencia de la FIC”, licenciado bajo CC BY‑NC‑SA 4.0. Puedes clonar el repositorio o descargar el PDF desde la sección de archivos.
Repositorios de IA local (IA para PC) que se ejecuta sin conexión

Estos proyectos permiten ejecutar modelos de lenguaje y chatbots en un PC sin necesidad de enviar datos a servidores externos. Son útiles si buscas una “mejor IA de PC” que funcione de forma privada y offline.

Repositorio / Proyecto	Características principales
nomic‑ai/gpt4all	GPT4All es una plataforma que permite ejecutar modelos de lenguaje grandes de forma privada en ordenadores de escritorio o portátiles. Su README destaca que no se necesitan API ni GPU dedicadas: basta con descargar la aplicación para empezar a usarla. El proyecto ofrece instaladores para Windows, macOS y Ubuntu y también una biblioteca Python para desarrolladores.
rodneylab/local‑ai‑llm‑playground	Conjunto de experimentos para ejecutar modelos LLM localmente usando las implementaciones Ollama y llama.cpp. En la introducción se explica que el objetivo es correr modelos de lenguaje en un ordenador doméstico usando Python o Rust, y que se proporcionan ejemplos para descargar y ejecutar modelos como Gemma 4 y Mistral. Además, se enumeran las ventajas de ejecutar LLMs localmente: soberanía de los datos, soporte sin conexión y posibilidad de afinado de modelos.
oobabooga/textgen	Este proyecto (antes conocido como text‑generation‑webui) es una aplicación de escritorio de código abierto para modelos de lenguaje locales. El README resalta que la interfaz es 100 % offline y privada, sin telemetría ni conexiones externas. Permite descargar modelos en formato GGUF, detectarlos automáticamente y ofrece instaladores portátiles para Windows, Linux y macOS.
lm‑studio‑ai	LM Studio es una aplicación de escritorio (código cerrado) que funciona como centro de control de modelos locales. Su página en GitHub describe un “espacio de trabajo de IA de escritorio privado” que permite ejecutar modelos en local, gestionar bibliotecas de modelos y acceder a una API local. Ofrece “workflows offline privados, sesiones de chat y herramientas para desarrolladores” y enumera los requisitos de hardware y pasos para iniciar una sesión local.
PromtEngineer/localGPT	Herramienta para chatear con tus documentos usando modelos GPT en tu dispositivo local. El apartado About del repositorio enfatiza que “No data leaves your device; es 100 % privado”. Está pensado para consulta de documentos propios (PDF, Word, etc.) y utiliza algoritmos de recuperación (RAG) en local.
Cómo descargar estos proyectos
Usa GitHub para clonar el repositorio: en cada página hay un botón “Code” que permite copiar el enlace HTTPS (por ejemplo, https://github.com/ligi/SurvivalManual.git). Ejecuta git clone <enlace> desde tu terminal para obtener todos los archivos de la wiki o del proyecto.
Descargas directas o releases: muchos proyectos publican archivos de lanzamiento (APK, ePub, ZIP o instaladores). Busca la pestaña Releases en cada repositorio. Por ejemplo, la wiki del Nuke Survival Toolkit ofrece un ZIP con la wiki offline y GPT4All proporciona instaladores para cada sistema.
Repositorios con Wikis: si solo te interesa la documentación, algunos proyectos alojan su contenido en la pestaña Wiki. Puedes navegar cada página de la wiki o usar herramientas como git clone <repo>.wiki.git para clonar la wiki completa.
Revisa las licencias: la mayoría de los manuales de supervivencia usan licencias libres (GPL, MIT, CC BY‑NC‑SA). Asegúrate de respetar las condiciones de uso.
Recomendación final

Los repositorios listados ofrecen un buen punto de partida para disponer de manuales de supervivencia sin conexión y herramientas de IA local para PC. El SurvivalManual de Ligi y su versión en ePub son los recursos más completos y fáciles de descargar para disponer de un compendio de técnicas de supervivencia offline. Para ejecutar inteligencia artificial en tu ordenador, proyectos como GPT4All y textgen te permiten descargar modelos y trabajar en privado sin depender de servidores externos. Según tus necesidades (manuales impresos o aplicaciones de IA), elige los repositorios correspondientes y sigue las instrucciones de descarga para tener tu biblioteca de supervivencia y tu asistente de IA siempre disponibles.
