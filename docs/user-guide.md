# User Guide

1. Start the app.
2. Choose a library directory and disk budget.
3. Pick a profile.
4. Download sources, verify them, and index practical text files.
5. Start Kiwix when ZIM files are downloaded.
6. Search indexed content without AI.
7. Use the local AI panel when Ollama and a model are installed.

All service URLs bind to `127.0.0.1` by default.
